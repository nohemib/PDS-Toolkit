# PDS Toolkit

Python toolkit for Digital Signal Processing exercises and experiments.

This project is being developed as part of the Master's Degree in
Advanced Technology at UPIITA-IPN.

The goal is to create reusable Python functions for signal generation,
signal transformations, visualization, and future Digital Signal
Processing applications.

## Planned Modules

### Signal Generation

- Sinusoidal signals
- Exponential signals
- Unit step
- Unit impulse
- Rectangular signals
- Triangular signals

### Signal Operations

- Amplitude scaling
- Addition of constants
- Time shifting
- Time scaling
- Time folding
- General time transformations

### Visualization

- Individual plots
- Signal comparison using subplots
- Overlaid signals
- Multiple-signal grids
